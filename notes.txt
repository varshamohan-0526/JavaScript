1.What is a variable in JavaScript?
  A variable in JavaScript is a named container used to store data or values that can be used and changed in a program.

2.What are the three keywords used to create variables?
  *let
  *var
  *const

3.Write the syntax to create a variable using var?
   syntax: var variable_name=value;

4.Write the syntax to create a variable using let?
   syntax: let variable_name=value;

5.Write the syntax to create a variable using const?
   syntax: const variable_name=value;

6. What is declaration?
   Declaration means creating a variable without assigning a value.
   syntax:let age;

7. What is initialization?
   Initialization means assigning a value to a variable for the first time.
   syntax:let age = 25;

8. What is reassignment?
   Reassignment means changing the value of an existing variable.
   syntax:let age = 25;
          age = 30;


9. What is redeclaration?
   Redeclaration means declaring the same variable again using the same keyword within the same scope.
   syntax:var x = 10;
          var x = 20;

10. Which keyword allows redeclaration?

11. Which keyword allows reassignment?

44.Difference between let and const:

   | `let`                      | `const`                    
   | -------------------------- | -------------------------- |
   | Can be reassigned          | Cannot be reassigned       |
   | Initialization is optional | Initialization is required |
   | Example: `let x = 10;`     | Example: `const x = 10;`   |

45.Difference between var and const:

   | `var`                      | `const`                    |
   | -------------------------- | -------------------------- |
   | Can be reassigned          | Cannot be reassigned       |
   | Can be redeclared          | Cannot be redeclared       |
   | Initialization is optional | Initialization is required |
   | Function-scoped            | Block-scoped               |
